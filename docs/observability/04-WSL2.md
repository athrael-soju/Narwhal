# Monitor a WSL2 development fleet

In this setup the fleet runs in WSL2 on your workstation, and Prometheus and Grafana run on a homelab machine. Two SSH tunnels connect them: one lets the homelab scrape the fleet, and the other lets your Windows browser reach Grafana. This gives the same Narwhal Orchestrator dashboard and the same `narwhal-router` and `engines` Prometheus jobs as a full deployment.

## Before you start

- `homelab` must be an SSH host alias that works from both WSL2 and Windows. Verify with `ssh homelab true` in each.
- Start the fleet with `narwhal dev up` and confirm it with `narwhal dev verify`.
- The homelab needs the same [prerequisites](01-Start-and-Verify.md#before-you-start) as a router host: Linux, Docker Engine with the Compose plugin, Python 3.11 or newer, and `curl`.

The examples assume the four-engine [RTX 5090 reference](../dev/08-RTX-5090-Reference.md) fleet in the default instance directory, `runs/dev`, and a Narwhal checkout at `~/projects/Narwhal` on the homelab. The fleet document is copied to `runs/workstation` there. With a different engine count, forward one port per engine; each engine and the router yield one scrape series.

## Copy the fleet document

From WSL2:

```bash
dev_run=$(python -c 'import json; print(json.load(open("runs/dev/lifecycle.json"))["run"])')
ssh homelab 'mkdir -p ~/projects/Narwhal/runs/workstation'
scp "$dev_run/fleet.json" homelab:projects/Narwhal/runs/workstation/fleet.json
```

## Let the homelab scrape WSL2

The fleet listens on loopback inside WSL2. Open reverse tunnels for the router and engine ports and keep them running while the fleet is up:

```bash
ssh -NT -o ExitOnForwardFailure=yes -o ServerAliveInterval=30 \
  -R 127.0.0.1:18000:127.0.0.1:18000 \
  -R 127.0.0.1:18101:127.0.0.1:18101 \
  -R 127.0.0.1:18102:127.0.0.1:18102 \
  -R 127.0.0.1:18103:127.0.0.1:18103 \
  -R 127.0.0.1:18104:127.0.0.1:18104 \
  homelab
```

These are the default router port and the four engine ports.

- If you ran `narwhal dev init --port-base`, forward your ports instead.
- If another SSH or VS Code forward holds one of these ports on the homelab, choose a different remote port.

When a remote port differs from the fleet's port, set the matching engine `url` in the copied `fleet.json` (or `NARWHAL_ROUTER_URL` for the router) to the remote port. Prometheus scrapes the addresses listed there.

## Open Grafana from Windows

In PowerShell, open a second tunnel for your browser:

```powershell
ssh -NT -o ExitOnForwardFailure=yes -o ServerAliveInterval=30 `
  -L 127.0.0.1:33000:127.0.0.1:3000 `
  -L 127.0.0.1:39090:127.0.0.1:9090 homelab
```

## Start monitoring on the homelab

From the homelab checkout:

```bash
NARWHAL_FLEET=runs/workstation/fleet.json \
NARWHAL_ROUTER_URL=http://127.0.0.1:18000 \
make observe
```

If a monitoring stack is already running, regenerate its target files in the directory Prometheus mounts for file-based discovery:

```bash
prometheus_targets=/path/to/prometheus/targets
.venv/bin/python -m tools.observability.make_targets \
  runs/workstation/fleet.json \
  --router-url http://127.0.0.1:18000 \
  --output-dir "$prometheus_targets"
```

Prometheus loads the new files automatically. Each engine entry carries an `iid` label that the dashboard uses to match engines to their roles.

## Check that it works

On the homelab, run:

```bash
curl -fsSG http://127.0.0.1:9090/api/v1/query \
  --data-urlencode 'query=up{job=~"narwhal-router|engines"}'
curl -fsSG http://127.0.0.1:9090/api/v1/query \
  --data-urlencode 'query=narwhal_router_ready{job="narwhal-router"}'
```

Expect five `up` series (the router plus four engines) and `narwhal_router_ready`, all with value `1`.

Then open `http://127.0.0.1:33000/d/narwhal-router/narwhal-orchestrator` in your Windows browser, pick the current router, and send requests through Narwhal. The request and token panels show activity, and the engine table lists four engines with pool assignments and role history.

## Shut down

Run `narwhal dev down`, then close both SSH tunnels. Prometheus on the homelab keeps the collected metrics until its retention period expires.
